环境说明

这些限制不是页面问题，而是浏览器安全模型或实验状态要求。

  • `getUserMedia()` / `getDisplayMedia()` / `selectAudioOutput()` 需要用户授权。权限
  • `getDisplayMedia()`、Region Capture、Element Capture 可能要求 HTTPS 或特定浏览器版本。安全上下文
  • `Translator` / `LanguageDetector` / `Summarizer` / `Writer` / `Rewriter` 属于实验性 AI API。实验性
  • `RTCRtpScriptTransform`、`WebTransport` 等高级能力通常需要特定服务端或实验标志。依赖环境
  • `ViewTransition`、`Navigation`、`Sanitizer`、`CompressionStream`、`WebGPU` 可通过能力检测快速确认可用性。适合本地验收
