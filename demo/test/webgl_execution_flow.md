# WebGL Worker 执行流程图

```mermaid
graph TD
    A[Web Worker 启动] --> B{接收消息类型};
    B -->|INIT| C[初始化渲染环境];
    B -->|DRAW| D[执行渲染操作];
    B -->|DESTROY| E[清理资源并关闭];
    
    C --> C1{请求 WebGL 模式?};
    C1 -->|是| C2[尝试创建 WebGL 上下文];
    C1 -->|否或 WebGL 不可用| C3[创建 Canvas2D 上下文];
    
    C2 --> C4{WebGL 上下文创建成功?};
    C4 -->|是| C5[初始化 WebGL 环境];
    C4 -->|否| C3;
    C5 --> C6[设置渲染模式为 WebGL];
    C3 --> C7[设置渲染模式为 Canvas2D];
    
    C6 --> C8[向主线程发送 READY 消息];
    C7 --> C8;
    
    D --> D1{当前渲染模式?};
    D1 -->|WebGL| D2[调用 drawWebGL 函数];
    D1 -->|Canvas2D| D3[调用 drawCanvas2D 函数];
    
    D2 --> D4[清除画布背景];
    D4 --> D5[计算网格布局参数];
    D5 --> D6[遍历视频帧数组];
    D6 --> D7{纹理是否已创建?};
    D7 -->|否| D8[创建并配置新纹理];
    D7 -->|是| D9[绑定现有纹理];
    D8 --> D10[上传视频帧到纹理];
    D9 --> D10;
    D10 --> D11[计算视口位置];
    D11 --> D12[设置视口];
    D12 --> D13[绘制图元];
    D13 --> D14[关闭视频帧];
    D14 --> D15{还有更多帧?};
    D15 -->|是| D6;
    D15 -->|否| D16[强制刷新渲染];
    D16 --> D17[向主线程发送 DONE 消息];
    
    D3 --> D18{视频源数量 < 4?};
    D18 -->|是| D19[用黑色填充画布];
    D18 -->|否| D20[跳过背景填充];
    D19 --> D21[计算网格布局参数];
    D20 --> D21;
    D21 --> D22[遍历视频帧数组];
    D22 --> D23[计算绘制位置];
    D23 --> D24[绘制视频帧];
    D24 --> D25[关闭视频帧];
    D25 --> D26{还有更多帧?};
    D26 -->|是| D22;
    D26 -->|否| D17;
    
    E --> E1{是否使用 WebGL?};
    E1 -->|是| E2[删除所有纹理对象];
    E1 -->|否| E3[跳过 WebGL 清理];
    E2 --> E4[主动丢失 WebGL 上下文];
    E3 --> E4;
    E4 --> E5[关闭 Web Worker];
```

## 详细说明

### 1. 消息处理流程
Web Worker 通过 `self.onmessage` 监听来自主线程的消息，根据不同消息类型执行不同操作：
- `INIT`: 初始化渲染环境
- `DRAW`: 执行渲染操作
- `DESTROY`: 清理资源并关闭 Worker

### 2. 初始化过程
当收到 `INIT` 消息时：
1. 首先检查是否请求 WebGL 模式
2. 如果是，则尝试创建 WebGL 上下文（优先 WebGL2，回退到 WebGL1）
3. 如果 WebGL 不可用或未请求，则创建 Canvas2D 上下文
4. 成功初始化后，向主线程发送 READY 消息

### 3. 渲染过程
当收到 `DRAW` 消息时：
1. 根据当前渲染模式选择 WebGL 或 Canvas2D 渲染路径
2. WebGL 渲染：
   - 清除画布背景
   - 计算网格布局（支持多路视频源）
   - 对每帧视频：
     * 检查并创建纹理（如需要）
     * 上传视频帧到纹理
     * 计算并设置视口位置
     * 绘制图元
     * 关闭视频帧以释放内存
   - 强制刷新渲染
3. Canvas2D 渲染：
   - 必要时填充背景
   - 计算网格布局
   - 对每帧视频：
     * 计算绘制位置
     * 绘制视频帧
     * 关闭视频帧以释放内存

### 4. 资源清理过程
当收到 `DESTROY` 消息时：
1. 如果使用了 WebGL，删除所有创建的纹理对象
2. 主动丢失 WebGL 上下文以释放 GPU 资源
3. 关闭 Web Worker
