Issues

mediaEffectsIssue 事件与 message 清单

这份文档用于排查当前媒体效果管线问题。对外事件只保留 module 和 message，更细信息留在实例 issue 快照和 logger。

1. 对外事件结构

session.on('mediaEffectsIssue', ({ module, message }) => {
  console.log(module, message);
});
{
  module: 'AiNS' | 'MediaEffectsComposer',
  message: '...'
}

内部 issue 可能包含 component、stage、severity、fallbackApplied、degraded、details，这些字段不作为对外事件稳定负载。

2. 上报链路

MediaEffectsComposer child module
  -> MediaEffectsComposer._recordIssue()
  -> MediaPipeline.emitMediaEffectsIssue()
  -> RTCSession._emitMediaEffectsIssue()
  -> session.emit('mediaEffectsIssue', { module, message })

AiNoiseSuppression / AiNSWorkletRuntime
  -> AiNoiseSuppression._reportIssue()
  -> MediaPipeline.emitMediaEffectsIssue()
  -> RTCSession._emitMediaEffectsIssue()
  -> session.emit('mediaEffectsIssue', { module, message })

5. 处理策略

模块用户提示技术处理
AiNS降噪不可用，已回退原始音频。保留通话，查看 AiNS capability 和 issues。
MediaEffectsComposer 单效果失败虚拟背景或水印处理失败，已关闭该效果。只关失败效果，不直接挂断。
MediaEffectsComposer 主链路失败视频效果不可用，已回退原始摄像头流。查看 render/output/audio issue，必要时重建 composer。
