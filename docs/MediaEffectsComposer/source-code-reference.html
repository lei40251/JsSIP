先看这几条主链路

直接使用 Composer

new MediaEffectsComposer(videos, options)
  -> MediaEffectsComposerConfig.create(options)
  -> new AiVBState() / new Watermark()
  -> new Sources() / LayoutEngine() / OutputStream() / RenderLoop() / AudioMixer()
  -> addSource(initialVideos, initialSourceOptions)
  -> getOutput({ type })

视频输出

getOutput({ type: 'video' })
  -> _getVideoOutputSync()
  -> OutputStream.getVideoStream(drawFirstFrame)
  -> RenderLoop.renderFrame(force=true)
  -> LayoutEngine.createRenderPayload()
  -> renderer.render(payload)
  -> OutputStream.onFramePresented()

混合输出

getOutput({ type: 'mixed' })
  -> _getMixedOutput()
  -> _getVideoOutputSync()
  -> OutputStream.setMixedStream(videoStream)
  -> AudioMixer.getStableAudioStream()
  -> OutputStream.addAudioTracksToStream()

RTCSession 集成

RTCSession.updateMediaEffectsComposer(options)
  -> MediaPipeline.resolveMediaEffectsComposerOptions()
  -> resolveMediaEffectsComposerPatch() or rebuild
  -> composer.setConfig(patch)
  -> replace track when rebuild is needed
