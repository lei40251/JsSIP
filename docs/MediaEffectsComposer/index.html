核心流程速查

RTCSession 创建/更新媒体
  -> MediaPipeline.getUserMediaWithSessionPipeline()
  -> getGumConstraintsWithProcessorFlags()
  -> navigator.mediaDevices.getUserMedia()
  -> processMediaStream()
  -> applyAiNoiseSuppressionOnSdkGumStream()
  -> applyMediaEffectsComposerOnSdkGumStream()
  -> new MediaEffectsComposer([stream], ctorOptions)
  -> composer.getOutput({ type: hasAudio ? 'mixed' : 'video' })
  -> RTCSession 替换/发送 composer 输出轨
