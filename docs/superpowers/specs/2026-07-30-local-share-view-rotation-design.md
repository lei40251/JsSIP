# 共享桌面与白板本端旋转设计

## 背景

`demo/base-js/` 的共享浮层同时承载本端/远端共享桌面、共享白板以及透明标注层。
当前内容只能按原始方向显示。手机观看横向桌面，或 PC 观看手机竖向白板时，用户无法在
不旋转设备的情况下调整观看方向。

## 目标

- 在共享浮层标题栏提供“旋转90° / 恢复”两态按钮。
- 旋转只影响当前设备，不改变共享流、白板逻辑比例或其他参与端显示。
- 共享桌面和共享白板均支持顺时针 90° 显示。
- 旋转后继续支持画笔、橡皮、箭头、矩形和椭圆，触摸/鼠标落点必须准确。
- 保留现有 0～1 归一化标注协议、SIP INFO 时序和 SDK API。

## 状态与生命周期

新增本端视图状态 `shareViewRotated`，只允许 `false`（0°）和 `true`（顺时针 90°）。
该状态不写入 `board:open`、snapshot 或其他 SIP INFO payload。

- 点击“旋转90°”：切换到 90°，按钮文本改为“恢复”。
- 点击“恢复”：切换到 0°，按钮文本恢复为“旋转90°”。
- 最小化并恢复同一共享浮层：保留当前旋转状态。
- 关闭共享浮层：重置为 0°。
- 共享来源在 `local`、`remote`、`whiteboard` 之间切换：重置为 0°，避免将上一来源的观看方向意外带入新来源。
- 浮层隐藏或没有有效共享模式时隐藏旋转按钮。

## 坐标模型

同步和存储始终使用未旋转的规范化坐标。顺时针 90° 仅在本端渲染和输入边界执行转换。

规范坐标到旋转视图坐标：

```text
viewX = 1 - sourceY
viewY = sourceX
```

旋转视图坐标到规范坐标：

```text
sourceX = viewY
sourceY = 1 - viewX
```

0° 时两个方向均直接返回原坐标。转换结果继续经过现有 `clamp(..., 0, 1)` 处理。

- 画笔和橡皮：逐点转换 `points`。
- 箭头、矩形和椭圆：转换 `start` 与 `end`。90° 后轴对齐矩形/椭圆仍可由两个对角点表达。
- 本端指针：先按当前 Stage 宽高归一化，再执行逆转换后写入 draft shape。
- 远端或历史 shape：数据保持规范坐标，只在 `makeNode()` 创建 Konva 节点时转换为视图坐标。

因此旋转端绘制的新标注发送给未旋转端时仍保持共享内容的原始方向；其他端不需要知道
本端是否旋转。

## 布局

### 共享白板

0° 使用发起端打开白板时锁定的 `boardAspectRatio`。90° 使用其倒数
`1 / boardAspectRatio`，然后沿用现有居中 `contain` 计算。白板背景和 Konva Stage
继续使用完全相同的矩形。

### 共享桌面

0° 保留当前按 `videoWidth / videoHeight` 的居中 `contain` 布局。
90° 使用 `videoHeight / videoWidth` 计算最终可见边界：

- 视频元素本身使用旋转前的宽高，围绕容器中心顺时针旋转 90°；
- 旋转后的视频可见边界等于计算出的 `contain` 矩形；
- Konva Stage 不做 CSS 旋转，而是直接占据旋转后的可见边界，并用本端坐标转换绘制 shape；
- 视频和 Stage 的中心、最终宽高必须一致，避免标注偏移。

不依赖浏览器自动反推旋转后的指针坐标，降低 Android WebView、微信 WebView、Safari
和鸿蒙浏览器的兼容风险。

## 文件职责

- `demo/base-js/index.html`：新增旋转按钮，展示真实 Demo 操作入口。
- `demo/base-js/js/app-helper.js`：维护本端旋转状态、按钮状态和共享浮层打开/关闭时的重置规则。
- `demo/base-js/js/app-events.js`：将旋转按钮直接绑定到轻量视图函数，保持 UI → Demo API 调用清晰。
- `demo/base-js/js/app-annotation.js`：实现纯坐标转换、旋转后的白板/视频/Stage 布局以及绘制逆映射。
- `demo/base-js/style/style.css`：只增加视频旋转所需的 transform origin 和按钮窄屏样式；不增加旋转动画或新布局层。
- `test/test-conference.js`：扩展现有 Demo helper/annotation VM 测试。

## 兼容与异常处理

- 视频 metadata 未就绪时继续使用现有 16:9 默认值；旋转时使用其倒数 9:16。
- 白板比例缺失或无效时，0° 使用当前容器；90° 也使用当前容器，不构造无效倒数。
- 点击旋转时若正在绘制，取消当前未提交 draft 且不发送该笔画，再重新布局，避免一条笔画跨越两套坐标系。
- 旋转只改变 DOM/Konva 展示，不触发重新协商、re-INVITE、track 替换或媒体流重建。
- 不修改 `dist/`、第三方 Konva 文件、SDK 导出或 `.d.ts`。

## 验证

自动测试覆盖：

- 0° 和 90° 的坐标正向/逆向转换互为逆操作。
- 自由点、箭头及矩形角点在 90° 下正确映射。
- 横向白板旋转后使用倒数比例并居中，恢复后返回原比例。
- 横向共享视频旋转后变为竖向 `contain`，视频最终边界与 Stage 一致。
- 旋转后指针逆映射生成规范 shape；未旋转端应用该 shape 时方向不变。
- 最小化/恢复保留状态；关闭或切换来源重置状态；按钮文本和显隐正确。

运行相关 Conference 测试、lint 和完整测试。浏览器环境允许时，分别用鼠标和触摸 viewport
检查桌面共享/白板的旋转、恢复、绘制、擦除和窗口 resize；无法覆盖的真实设备在交付说明
中列为未验证项。
