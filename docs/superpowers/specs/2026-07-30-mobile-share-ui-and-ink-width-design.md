# 小屏共享界面与标注线宽优化设计

## 目标

- 在 `767px` 及以下屏幕减少共享窗口顶部区域占用。
- 标注工具栏保持两行完整展示，不使用横向滚动。
- 相同线宽值不再因发起端画布尺寸不同而产生明显粗细差异。

## 设计

小屏标题栏保持单行：隐藏标题图标和副标题；旋转和最小化按钮显示图标与文字，其他操作按钮仅显示图标并保留无障碍名称。标注工具栏固定为两行布局：第一行放五个绘制工具，第二行放颜色、线宽及三个历史操作；隐藏分区标题和提示文案，不改变桌面端布局。

旋转按钮使用 `bi-arrow-90deg-right` 表达顺时针旋转 90°，最小化按钮使用 `bi-window-dash` 表达窗口最小化。小屏图标覆盖 Bootstrap Icons 的默认基线偏移，并由按钮的 flex 布局水平、垂直居中。

线宽使用固定 `640px` 参考短边归一化，即 `widthNorm = sliderValue / 640`。渲染仍按目标画布短边还原，因此手机和 PC 发起的标注保持一致的相对粗细，协议结构不变。

## 范围与验证

仅修改 `demo/base-js` 的响应式 CSS、标注线宽计算及相应测试，不修改 SDK API、标注消息结构或构建产物。测试覆盖固定参考线宽计算，并运行 Demo 相关测试、lint 与完整测试。
